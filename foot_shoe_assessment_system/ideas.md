Design Movement: リハビリテーション・サロン・ラボ
Core Principles:
1. 医療の堅さを残しつつ、患者が自分事として受け止めやすい温度感を持たせる。
2. 評価を“怖い診断”ではなく“改善の設計図”として提示する。
3. 専門性より先に理解しやすさ、理解しやすさより先に行動しやすさを置く。
4. 小さな成功体験を積めるUIで、依存ではなく自立を促す。
Color Philosophy:
生成り、砂色、苔色、濃紺を基調にする。木質の温かさと研究室の精度感を混ぜ、患者教育にも使いやすい安心感をつくる。警告色は強くせず、深い朱色で節度ある注意喚起とする。
Layout Paradigm:
左から右へ“評価→解釈→説明→行動”が流れる横断型ステップレイアウト。各ステップが帯状に連なり、最終的に推奨靴や患者説明文に着地する構成。
Signature Elements:
1. ステップごとの帯見出し
2. 柔らかな角ではなく適度に締まった角丸と影
3. 靴底や歩行軌跡を抽象化したパターン背景
Interaction Philosophy:
医療者には入力の速さ、患者には理解のしやすさを優先する。複雑な評価は折りたたみ、必要なときだけ展開し、主画面では“今何が問題か”を一目で示す。
Animation:
ステップ間の遷移は横方向の移動を基調にし、診断が進む感覚を与える。要点はハイライトが静かに差し替わる形で示し、過度な跳ねや回転は使わない。
Typography System:
見出しは Zen Old Mincho のような知性と情緒を持つ和文書体、本文は BIZ UDPゴシック系の読みやすい書体を採用。患者向け文面はやや大きめ、医療者向け数値は密度高めに組む。
</idea>
