# 統合的足部評価システム Web版 - 全機能実装計画

## 優先度1～9 全項目実装スケジュール

### PHASE 1: 足部評価を両足・荷重分離（4セット）に改善
- [ ] STEP 2 フォーム構造を「右足・左足」に分離
- [ ] 各足で「非荷重」「二脚荷重」の2条件を入力可能に
- [ ] 足長、足囲、足幅を各セット4回入力できるように改善
- [ ] 非荷重→二脚での変化量を自動計算（足囲、足幅）
- [ ] 左右差を自動検出（足長差、柔軟性差）
- [ ] TypeScript型定義を更新（FootAssessment型を4セット対応に）

### PHASE 2: 歩行評価をSTEP 4に独立 + 3軸フレーム実装
- [ ] STEP 3 から歩行評価を削除
- [ ] STEP 4 として新規作成
- [ ] 3軸フレーム（回内制御 × 前足部剛性 × 近位代償）を実装
- [ ] IC～LR フェーズの詳細選択肢を追加
  - [ ] 正常：踵接地明確、回内タイミング適切
  - [ ] 早期回内：踵接地直後に過度な回内
  - [ ] 強い回内：踵骨の内反が強い
  - [ ] 外側接地：踵の外側から接地
- [ ] MSt フェーズの詳細選択肢を追加
  - [ ] 正常：足部で安定、近位代償なし
  - [ ] 内側倒れ込み：ラテラルスラスト
  - [ ] 骨盤下垂：トレンデレンブルグ
  - [ ] 骨盤回旋増加：デュシャンヌ
- [ ] TSt フェーズの詳細選択肢を追加
  - [ ] 正常：アーチ形成良好、蹴り出し力強い
  - [ ] アーチ形成不良：2・3趾アーチが挙上しない
  - [ ] 早期離地：接地時間が短い
  - [ ] 接地時間延長：蹴り出しが遅い
  - [ ] 外側逃げ：踵骨が外反、小趾側で蹴り出す
- [ ] PSw フェーズの詳細選択肢を追加
  - [ ] 正常：toe off 明確、振り出し良好
  - [ ] toe off 不明確：蹴り出しが弱い
  - [ ] 足が引きずる：前足部の離地が遅い
- [ ] 各フェーズの「見ること」「解釈」を自動生成するロジック実装

### PHASE 3: 身体評価に直接数値入力 + 足首不安定性テスト
- [ ] 背屈可動域（膝伸展）をセレクトから数値入力（度）に変更
- [ ] 背屈可動域（膝屈曲）をセレクトから数値入力（度）に変更
- [ ] 母趾伸展を新規追加、数値入力（度）で実装
- [ ] 足首の不安定性テストを新規追加
  - [ ] セレクト：正常 / 軽度 / 中等度 / 重度
- [ ] UI：スライダーまたはスピナーで入力性を最適化

### PHASE 4: 評価サマリーを両足・荷重・変化量で分離表示
- [ ] JIS判定の表示形式を改善
  - [ ] 【右足】非荷重 / 二脚荷重 / 変化量
  - [ ] 【左足】非荷重 / 二脚荷重 / 変化量
  - [ ] 【左右差】足長差、柔軟性差
- [ ] 捨て寸の判定基準を「8-12mm」に修正
  - [ ] 適正：8-12mm
  - [ ] やや大：13-16mm
  - [ ] 大：17mm以上
  - [ ] 小：7mm以下
- [ ] 足部タイプを改名
  - [ ] 「煎餅タイプ」→「横広タイプ」
  - [ ] 「饅頭タイプ」→「甲高タイプ」
- [ ] 柔軟性評価を改善
  - [ ] 変化量に基づいて「柔軟性足」「標準足」「剛性足」を自動判定

### PHASE 5: インソール・オーバーラップテスト追加
- [ ] インソール・オーバーラップテストの入力フォームを追加

  - [ ] 患者インソール厚さ > 靴中敷き厚さ → 「⚠️ 入らない / 要調整」
- [ ] 結果に応じた対応案を自動表示

### PHASE 8: 診断結果から靴要件を自動生成 + マッチングロジック
- [ ] 診断結果 → 靴要件の変換ロジック実装
  - [ ] 背屈制限 < 10度 → トゥースプリング 15mm以上、ドロップ 12mm以上

  - [ ] 甲高タイプ → 甲の容積が高い
- [ ] 靴データベースとのマッチングロジック実装
  - [ ] 完全マッチ：すべての要件を満たす
  - [ ] 部分マッチ：70%以上の要件を満たす
